Privacy Policy

UploadReady

Last updated: September 20, 2026

Short version: UploadReady's file tools are designed to process supported files in your web browser. Files selected for these tools are not intentionally uploaded to or stored on an UploadReady server by the tool pages described on this website.

1. Information handled by the file tools

When you select an image or PDF in an UploadReady tool, the selected file may be read and processed by JavaScript running in your browser so that the requested operation can be performed. Examples include compression, resizing and format conversion.

2. File storage

The tool pages are designed so that the selected files are processed locally in the browser rather than intentionally uploaded to an UploadReady server. Downloaded files are saved by your browser according to your device and browser settings.

3. Third-party resources

Some UploadReady functionality may load third-party JavaScript libraries or other resources from external content delivery networks (CDNs). When your browser requests an external resource, the relevant provider may receive technical information associated with that web request. UploadReady does not control the privacy practices of third-party providers.

4. Website hosting

UploadReady is hosted using GitHub Pages. GitHub may process technical information such as requests, IP addresses and other information as described in GitHub's own policies.

5. Analytics and advertising

At the time this policy was published, UploadReady's tool pages do not intentionally send the selected files to an UploadReady analytics or advertising server. If analytics, advertising or other third-party services are added later, this policy should be updated to describe those services and the information they process.

6. Children's privacy

UploadReady is a general-purpose online utility. We do not intentionally collect personal information from children through the file-processing tools.

7. Security

Browser-based processing can reduce the need to transmit a selected file to a server, but no website or internet transmission can be guaranteed to be completely secure. Keep sensitive files off websites unless you are comfortable using the service.

8. Changes to this policy

This privacy policy may be updated when UploadReady's features, hosting or third-party services change. The “Last updated” date will be changed when material updates are made.

9. Contact

For privacy questions or concerns, use the contact method provided on the UploadReady website or repository.
